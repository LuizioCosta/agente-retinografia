# Agente de Retinografia

Aplicativo para celular que recebe uma retinografia colorida e apresenta o **laudo preliminar de triagem para glaucoma** em português do Brasil, com os mesmos modelos (EyeFlow V800: RETFound + MedGemma-27B) e o mesmo layout do notebook `EyeFlow_V800_Inferencia_Laudo_PTBR`.

➡️ **Comece pelo [GUIA_IMPLANTACAO.md](GUIA_IMPLANTACAO.md)**, que traz o passo a passo até o app instalado no celular.

> Ferramenta de pesquisa, sem validação clínica nem registro na ANVISA. O laudo é preliminar e precisa ser revisado por médico oftalmologista.
